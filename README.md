# Skills

个人 AI 工作流技能库，将日常办公中的操作经验整理为可复用的 `SKILL.md`。目前主要覆盖出差发票整理与费用报销。

## 技能一览

| Skill | 用途 | 主要产出 |
| --- | --- | --- |
| [Outlook 发票附件整理](outlook-invoice-organizer/SKILL.md) | 按发件人、日期和主题定位发票邮件，下载并分类保存附件 | 按出差地点、日期整理的发票文件与清单 |
| [Concur 发票报销](concur-invoice-reimbursement/SKILL.md) | 根据本地发票创建报销单、录入费用、分摊酒店明细并上传收据 | 已录入的报销单、费用核对结果与待处理事项 |

两个技能可衔接使用：**Outlook 查找发票 → 本地分类归档 → Concur 录入费用 → 核对金额与附件**。

## 如何使用

1. 将本仓库克隆到本地：

   ```bash
   git clone https://github.com/kaiqing1008/skills.git
   ```

2. 选择需要的技能，阅读对应目录中的 `SKILL.md`。
3. 按所用 AI 工具的技能加载机制，将整个技能目录放入其支持的位置，或让具备文件读取能力的助手读取对应 `SKILL.md` 并按步骤执行。
4. 提供本次任务的日期范围、文件夹路径和业务信息，再开始操作。

这些技能是操作指引，执行时需要宿主 AI 工具具备相应的桌面或浏览器操作、文件读写等能力。文档中的工具名称来自原使用环境，迁移到其他平台时需对应调整；本仓库未提供统一安装脚本。

## 使用示例

**整理发票**

> 请使用 outlook-invoice-organizer，整理 Outlook 中 10 月 20 日至 22 日与本次出差相关的发票附件，保存到我指定的文件夹，并列出结果。

**录入报销**

> 请使用 concur-invoice-reimbursement，根据我指定文件夹中的发票创建本次出差报销单。录入前先列出关键字段供我确认，完成后核对总额与附件。

## 使用前准备

- **Outlook**：已配置可访问的邮箱账户，明确邮件筛选条件和附件保存路径。
- **Concur**：具备相应系统权限，准备发票、行程单或酒店水单，并确认报销主题与业务理由；提取 PDF 文本时需要 `pdftotext`。
- **环境适配**：现有流程基于 macOS、Outlook 桌面端及特定企业的 Concur 配置。首次使用时，应核对本地路径、登录入口、费用类型与公司政策。
- **人工确认**：登录和验证码由用户完成；费用类型等业务判断按技能要求确认。当前流程覆盖报销单创建和费用录入，最终提交或审批需另行明确。

## 维护方式

每个技能使用独立目录，在 `SKILL.md` 中维护适用场景、前置条件、操作步骤和核对标准。修订直接更新原文件，通过 Git 保存版本历史，并在 `AGENTS.md` 中记录请求、产出和负责的 AI 平台。
