# Outlook 发票附件整理

从 Microsoft Outlook 中查找并整理发票相关的附件,用于报销单提交。

## 适用场景

- 用户需要从 Outlook 邮件中提取发票附件(如机票行程单、电子发票、滴滴行程单、餐饮发票等)
- 需要将附件按日期、类型或出差地点分类保存到本地文件夹
- 为 Concur 等报销系统准备发票文件

## 操作流程

### 1. 打开 Outlook 并定位目标邮件

- 使用 `computer_use` subagent 操作 macOS 桌面应用
- 启动 Outlook,进入对应邮箱账户的收件箱
- 根据用户提供的信息筛选邮件:
  - 发件人(如航空公司、滴滴出行、携程等)
  - 时间范围(如出差日期前后)
  - 主题关键词(如"发票"、"行程单"、"invoice"、"itinerary")

### 2. 确认发票邮件

- 逐个打开候选邮件,核对邮件内容确认是否为目标发票
- 记录邮件中的关键信息:发票金额、日期、类型(机票/餐饮/交通等)
- 确认附件是否为发票文件(通常为 PDF 或图片格式)

### 3. 下载并保存附件

- 在 Outlook 中右键点击附件 → "另存为"
- 或直接拖拽附件到目标文件夹
- 保存路径规则:
  - 根目录由用户指定(如 `<发票根目录>/`)
  - 按出差地点和日期命名子文件夹(如 `Yantai 8.11-8.13/`)
- 文件命名规范:
  - 机票发票: `{出发地}-{目的地} Invoice.pdf`
  - 机票行程单: `{出发地}-{目的地} Itinerary.pdf`
  - 餐饮发票: `Meal.pdf` 或 `meal.jpg`
  - 滴滴电子发票: `滴滴电子发票.pdf`
  - 滴滴行程单: `滴滴出行行程报销单.pdf`

### 4. 整理与核对

- 保存完成后,使用 `LS` 工具列出目标文件夹内容
- 核对所有发票文件是否齐全
- 向用户汇报整理结果,列出已保存的文件名清单

## 注意事项

- Outlook 桌面应用操作需通过 `computer_use` subagent 完成,无法直接通过 Shell 命令
- 下载附件时确保文件完整保存后再关闭邮件
- 如果用户提供了具体的保存路径,严格按照用户指定的路径保存
- 整理完成后,主动询问用户是否需要继续处理(如创建 Concur 报销单)
